# 場面台本（scenes_a.js = S0〜S3 / scenes_b.js = S4〜S7＋次の回）

`CONTRACT.md` の続き。遊ぶのは5歳児・指1本・文字なし・失敗なし。
**いちばん大事な決まり: どの瞬間も「次にやる1つの操作」が、世界の中の手がかり（光る・揺れる・ママの手の指さし/お手本・音・カメラの構図）で1〜2秒で分かること。**

## 共通の決まり
- 場面は `G.Director.add('S0'..'S7', {enter, update, exit})`。scenes_a.js は `G.Scenes.registerA()`、scenes_b.js は `G.Scenes.registerB()` を生やす（`G.Scenes = G.Scenes || {}`）。補助関数は各ファイルの IIFE 内に閉じる（共有名を増やさない）。
- 主役として触れる物は一度に1つ。主役は `G.Hint.set(...)`（halo＋pulse、放置で L1→L2 の幽霊指）で示す。ほかの物は光らせない。
- 触ったら 100ms 以内に動きと音で応える（pointerdown の時点で反応を始める。アニメの完了を待たない）。
- pointerdown のたびに `G.Hint.poke()`。
- 当たり判定は大きく: `G.Input.screenDist(ev, 対象の世界位置) < 60〜80px` または pick。置き先は吸着（磁石）: 目標から世界 0.10m 以内（または目標側の板/皿の上）で離せば目標へ収まる。外れた所で離したら、責めずに静かに元へ戻る（否定の音なし）。
- ママのお手本アニメ中は主役の操作を受け付けないが、どこを触っても小さく応える（例: 触った物が少し揺れる＋`tap`）。お手本は短く（各 1.5〜5 秒）。
- 子どもの手: 操作に合わせて `G.W.hands.cR`（対象が画面左寄りなら `cL`）が実際に動く（押す・握る・つまむ・運ぶ）。指の位置に物が追従し（指数追従 rate 18/s 程度、持ち上げ 3〜5cm、速度で少し傾く）、手は物に付いて動く。操作していない時は `rest()`。
- ママの手 `mL/mR` はお手本と指さしと手伝い。使わない時は `rest()`。ママの手や物を触ると小さく応える（指を ひらひら＋`tap`）。
- 連打・多重入力で壊れない（アニメ中フラグ、ドラッグ中に場面が変わっても up を必ず処理）。`exit()` で自分の tween/湯気/ヒントを必ず止める。`enter()` は途中状態から呼ばれても落ちない。
- 状態は `G.W.state` と `G.W.riceC / riceM / riceTiny / minis` に置き、場面をまたいで保つ。
- 音は `G.Audio.play(name, opts)`（無くても落ちない呼び方 `G.Audio && G.Audio.play(...)` か小さなラッパ）。

## S0 ふた（scenes_a）
- enter: `G.Cam.frame(G.W.FRAMES.cooker)`（初回は dur 0）。ふたは閉、LED 点灯、蒸気口から細い湯気。0.6秒後にママの右手が point でボタンの上へ来て、空中で とん とん と指さして待機へ戻る（2回目以降の回は省略可）。
- 主役: ボタン。`G.Hint.set({kind:'tap', at: ボタン位置, object: cooker.button})`。
- 操作: ボタンを押す → 即 `pressButton(1)`＋`button` 音、子どもの右手の人差し指が押しに来る（飾り。遅れてよい）。→ ふたが開く（`setLid` 0→1、0.7秒、outBack）＋`lidOpen`＋大きな湯気の puff＋`steam`、以後は釜から穏やかな湯気。最初のタッチで `G.Audio.ambience(true)`, `G.Audio.music(true)`。
- ボタン以外の炊飯器を触る: ふたが かたっ と揺れて小さな湯気（ボタンが正解だと気づける）。
- 0.9秒後に S1 へ。

## S1 よそう（scenes_a）

- ママのお手本（約3.5秒）: ママの右手がしゃもじ（炊飯器の右脇）を握る → 釜へ → すくう（`scoop`、`potRice.dig()`、しゃもじに `createScoop`）→ ママのまな板の中央へ運んで のせる（`G.W.riceM = createBody({size:0.043})`、`plop`、小さな湯気）→ しゃもじを釜のごはんに差して置く（へらがごはんの中、柄が手前=子ども側へ斜めに突き出る）→ 手は待機へ。
- 主役: しゃもじ。`G.Hint.set({kind:'drag', at: しゃもじの柄, to: 子どものまな板中央, object: shamoji})`。子どものまな板中央にも淡い halo（置き先）。
- 操作: しゃもじに触れる → 即、子どもの右手が柄を握り、ごはんの山がのった状態で持ち上がる（`scoop` 音、`dig()`、湯気が山についてくる）。指に追従。離す → **どこで離しても**子どものまな板へ届けて のせる（失敗なし。まな板の近くなら その場から、遠ければ手が運ぶ）: 1杯目は `G.W.riceC = createBody({size:0.026})`、`plop`＋湯気＋粒が2〜3粒こぼれる。しゃもじは手が釜へ戻す。
- 発見: 具を入れる前なら、もう一度すくうと大きくなる（2杯目 0.030、3杯目 0.034 で上限。`state.scoops`）。主役の光は次（小皿）へ移るが、しゃもじは触れば応える。
- 1杯目がのったら 0.6秒後に S2 へ。

## S2 ぐ（scenes_a）
- enter: `G.Cam.frame(FRAMES.fill, 1.0)`。
- ママのお手本（約1.6秒）: ママの手が小皿から具（回ごとに うめ→しゃけ→こんぶ、`state.mamaFilling`）をつまんで自分のごはんのくぼみへ（`riceM.setFilling`、`drop`）。
- 主役: 3つの小皿（ひとまとまりの光）。小皿の具が左→右へ順に やさしく脈動。`G.Hint.set({kind:'drag', at: 真ん中の小皿, to: riceC の位置})`。riceC のくぼみにも小さな halo。
- 操作: 小皿に触れる → 即、子どもの手が一口分をつまむ（`createFillingPiece(kind)`、`pick`）。指に追従。子どものまな板の上か riceC の近くで離す → くぼみへ弧を描いて入る（`riceC.setFilling(kind)`、`drop`、粒が少しはねる）、`state.filling = kind`。別の所で離す → 小皿へ静かに戻る。
- 入れ直し（逆戻りOK）: S2 の間は別の具を運ぶと入れ替わる（前の具は ぴょんと小皿へ帰る）。
- 具が入ったら 0.7秒後に S3 へ（S3 に入ったら小皿としゃもじは主役でなくなり、触っても軽く揺れるだけ）。

## S3 かたち＋にぎる（scenes_a・ゲームの中心）
両手を左右の「壁」にしてごはんをはさむ。**上から見た両手の形がそのままおにぎりの形**。形の値 t: 0=`| |` たわら / 0.5=`/ \` さんかく / 1=`( )` まる。

### 壁リグ
`wallRig(handL, handR, center, size, t, gap, press)` を作る: ごはん中心 `center`（まな板上）、等価半径 `size`、形 t、開き `gap`(m)、押し込み `press` 0..1 から、左右対称に手首の位置・回転・ポーズを決める。
- 手は横倒し（小指側の縁が板、手のひらが内向きでわずかに下向き、親指側が上）。t=0: 2本がまっすぐ平行（指先が -Z）。t=0.5: 手首（かかと）を支点に内へ回り、指先どうしがごはんの奥（-Z 側）で合う山形。t=1: 指全体が丸くカーブしてごはんを囲む。0〜0.5〜1 は連続に補間。
- gap=0, press=0 で手のひらの内側が `G.Rice.targetOutline(t)`×size の輪郭にちょうど触れる。press=1 で 約 size×0.08 内へ（`body.setPress` と一致）。
- スクリーンショットで上から見て `| |` `/ \` `( )` がはっきり読めるまで調整する（手役の報告にある推奨の回転の作り方を使う）。

### 流れ
- enter: `G.Cam.frame(FRAMES.shape, 1.0)`。
- ママのお手本（約5秒）: ①ママの両手が自分のごはんの左右へ（t=0、少し開く）→ ②`state.mamaT` の形へ すーっと変える（終わりに `tick`、指先を 0.8秒 光らせる `setGlow`）→ ③ぎゅっ×3（寄せる 0.25秒＋`squish`、`riceM.setPress`、離す時 `riceM.squeeze(mamaT, 0.45)`）→ 3回目で完成（`done` 小さめ）→ ④両手を少し開いて、形を保ったまま おにぎりの左右に置いて見せ続ける（お手本として残す。放置が 6秒続くたび、形を作り直して見せる: 開く→形→指先が光る）。
- 子どもの番: 子どもの両手がごはんの左右へ（形は `state.t`。初回は 0、回をまたいで保持）。
- 触る場所は2つの帯に分ける（どちらも大きく）:
  - **指先の帯**（ごはんより奥。両手の指先のあたり）= 形を変える。横に引くと形が連続に変わる（中心へ寄せると t が増える、外へ引くと減る。指 2.5cm で t が 0.5 変わる程度。左右どちらの手を引いても両手が対称に動く）。離すと 0 / 0.5 / 1 の近い方へ吸着（0.15秒、`tick`）。**短いタップなら次の形へ進む**（0→0.5→1→0）。ママと同じ形になった瞬間: `match` のチャイム＋両者の指先が同時に光る＋小さなきらめき。
  - **ごはんの帯**（ごはんと手のひら）= ぎゅっ。押した瞬間から手が寄り始め（押している間 press が 0.35秒で 1 へ。短いタップでも最低 0.6 までは寄る）、`squeezeStart/Set` と `riceC.setPress(p)`。離すと `riceC.squeeze(state.t, 0.22 + 0.20×press)`、`release`、手が少し開く。強く握ると小さな湯気。握るたび手にごはん粒がつく（`state.grains`++、最大6、`setGrains`）＋粒が2〜3 板にこぼれる。
- 主役の切り替え（放置時の案内）: まだ1回も握っておらず `state.t ≠ state.mamaT` の間は **指先**（`setGlow` 脈動＋`G.Hint.set({kind:'drag', at: 子どもの右手の指先, to: 寄せる/開く先})`）。形が合った後、または1回でも握った後は **ごはん**（`G.Hint.set({kind:'press', at: riceC, object: riceC.group})`、指先の光は消す）。どちらの帯もいつでも触れる（形を変えずに握ってもよい＝どの形も正解）。途中で形を変えて握ると混ざった形になる（発見）。
- 完成: `riceC.formed >= 1` → 両手が ぱっと開く、`done`＋きらめき。ママと同じ形（`|t - mamaT| < 0.1` かつ輪郭が目標に近い）なら `match`＋2つのおにぎりが一緒に光る＋ママの手が小さく拍手（`clap` 小 ×2）。違う形でもママの手は嬉しそうに ひらひら＋`yum`（否定なし）。
- 1.5秒後、4本の手を `rest()` にして `G.Director.go('S4')`。

### S3 終了時の引き継ぎ状態（scenes_b はこれを前提にする）
`G.W.riceC`: 子どものまな板中央、formed=1、filling あり。`G.W.riceM`: ママのまな板中央、formed=1、形 mamaT、filling=mamaFilling。4本の手は待機。炊飯器は開、しゃもじは釜。盆は `P.tray`、大皿は画面外 `P.plateOut`。`state.t, mamaT, filling, mamaFilling, grains, round`。

## S4 のり（scenes_b）
- enter: `G.Cam.frame(FRAMES.nori, 0.6)`。
- ママのお手本（約1.5秒）: ママの左手がのりの帯を自分のおにぎりへ（`riceM.setNori` 0→1 を 0.5秒、`nori`）。続いてママの右手が、もう1枚の のり（`createNoriStrip`、幅≈riceC.size×0.95）をつまんで、2枚のまな板の間・右寄り（x≈0.10、高さ≈0.07、z は2枚のまな板の境目あたり）へ差し出し、小さく ゆらゆら。
- 主役: 差し出された のり。`G.Hint.set({kind:'drag', at: のり, to: riceC})`。
- 操作: のりに触れる → 即、子どもの手がつまむ（`pick`、ママの手は離して待機へ）。指に追従（少し はためく）。子どものまな板の上か riceC の近くで離す → 手前の縁に合わせて巻きつく（`riceC.setNori` 0→1 を 0.45秒、`nori`、黒い小さな かけらが少し）。別の所で離す → 差し出し位置のカウンターに ふわりと戻る（そこで光り続ける）。
- 0.8秒後に S5。

## S5 おさら（scenes_b）
- enter: ママの両手で、盆を左へ（`P.trayOut`）、大皿を右から `P.plateIn` へ同時にすべらせる（`slide`、0.9秒）。湯のみは使わない。`G.Cam.frame(FRAMES.plate, 1.0)`。
- ママ: 右手が自分のおにぎりを上からつかんで皿の `slots.mama` へ（`plate` 音）→ 隣の `slots.child` を とん とん と指さして待機へ。
- 主役: 自分のおにぎり。`G.Hint.set({kind:'drag', at: riceC, to: slots.child の世界位置, object: riceC.group})`。皿の child スロットに halo。
- 操作: おにぎりに触れる → 即、子どもの手が上からつかんで持ち上げる（`pick`）。皿の上（中心から 0.14m 以内）で離す → スロットへ（`plate`＋きらめき）。別の所で離す → まな板へ静かに戻る。
- 並んだら（同じ形なら `match`＋両方きらめき）、1.0秒後に S6。

## S6 ちび（scenes_b・くすっと笑える所）
- enter: 子どものまな板に、握った時にこぼれた粒が少し散っている。ママの右手の人差し指が それを すっと集めて小さな塊に（`G.W.riceTiny = createBody({size:0.012})`、formed 0、板の中央、`plop` 高め）→ そばを とん とん と指さして待機へ。
- 主役: ちびの塊。`G.Hint.set({kind:'press', at: riceTiny, object: riceTiny.group})`。
- 操作: 塊を押す → 即、子どもの両手の指先が左右からつまむように寄る（小さな壁。形は `state.t`）、`squish`（pitch 1.6）→ 離すと `riceTiny.squeeze(state.t, 1)` で一発完成、`pop`＋きらめき、ちびおにぎりが ぴょんと跳ねて着地。ママの手が小刻みに拍手（`clap` 小・高め）。
- 続いて主役: ちびおにぎりを皿へ（`G.Hint.set({kind:'drag', at: riceTiny, to: 次の空き tiny スロット})`、スロットに halo）。つまんで運び、皿の上で離すとスロットへ（`plate` 高め）。`G.W.minis` に追加（5個を超えたら一番古いものが しゅっと消えてから置く）、`G.Save.set({minis: 直近5個の serialize(), round})`。
- 大・中・ちびが並ぶ。0.8秒後に S7。

## S7 たべる → おしまい → 次の回（scenes_b）
- enter: `G.Cam.frame(FRAMES.eat, 1.0)`。
- 主役: 皿の上の自分のおにぎり。`G.Hint.set({kind:'tap', at: riceC, object: riceC.group})`。
- 操作: おにぎりを触る → 即 ぴょこっと動き `pick`、子どもの手が上からつかんで手前（画面下の外、カメラの方 (0.03, 0.30, 0.42) あたり）へ運ぶ（0.45秒）→ `munch` → 画面外で `riceC.bite()` → 皿へ戻す（0.45秒）。かじり跡が見える。
  - 1口目: `yum` 小さめ。同時にママも自分のを一口（右手が画面右下の外へ運んで戻す、`riceM.bite()`）。
  - 2口目: 中の具が見える。具ごとの反応 — うめ: `sour`＋`G.Cam.shake` 小＋子どもの両手が ぶるぶるっ（くすっと笑える）/ しゃけ: `yum`＋手が ぴょんと弾む / こんぶ: `yum`（pitch 0.8）＋手がゆっくり うんうん。
  - 3口目: 食べ終わり。手が戻って両手を ぱんぱん と払う（`setGrains(0)`、`tap`×2）。ママも食べ終える。
  - アニメ中の連打は無視（キューしない）。
- 食べ終わったら: ママの手（左）が中央（2枚のまな板の間あたり、高さ≈0.10）へ、パー（open）で手のひらを上・少し子ども向きに出す。指先が光る。`G.Hint.set({kind:'tap', at: ママの手のひら})`。
- 操作: ママの手のひらを触る → 即、子どもの手がパーで ぱちん（0.12秒）、`clap`＋大きなきらめき＋`G.Cam.shake` 微小。何度でもできる。最初の1回でおしまいへ。
- おしまい（約5秒・やさしく）: `ending` のフレーズ、ママの手が子どもの手の甲を ぽん ぽん と やさしくなでる（`tap` 小）、皿のちびおにぎりたちの上に きらめきが ゆっくり舞う、カメラはゆっくり皿へ。`state.round++`、保存。
- 次の回: `G.W.resetRound()`（ふたが閉まる `lidClose`、盆と皿が入れ替わる `slide`、手は待機）→ `state.mamaT = G.W.SHAPES[round % 3]`、`state.mamaFilling` も次へ → `G.Director.go('S0')`。ボタンがまた光る。ちびおにぎりは皿に残り、次の S5 で皿と一緒に戻ってくる。
