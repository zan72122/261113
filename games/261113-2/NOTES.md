# にぎにぎ！ママとおなじおにぎり（gf-261113-nx2）

## 起動方法
- `index.html` をそのまま開く（`file://` でも Pages のサブフォルダでも動く。外部読み込みなし・1ファイル）。
- 作り直す時: `node build.mjs`（`src/` の各 JS と three.js r160 を `index.html` に埋め込む）。開発中は `src/dev.html` を直接開ける。
- 設計は `src/CONTRACT.md`（座標系とモジュール API）と `src/SCENES.md`（場面台本）。

## お話
炊飯器のふたを開ける → しゃもじでよそう → 具（うめ・しゃけ・こんぶ）を入れる → ママの手の形をまねて「ぎゅっ」（`| |` たわら / `/ \` さんかく / `( )` まる。両手の形がそのままおにぎりの形になる）→ のり → お皿にならべる → ちびおにぎり → たべる（うめは すっぱい！）→ ハイタッチ → 次の回（ママの形が変わる。ちびおにぎりは皿に残る）。

## 確認したこと（最小限）
- 390×844 で読み込み・開始時にコンソールエラーなし（`file://`）。WebGL を切ると埋め込みの静止画に切り替わる。
- S0〜S7 → 次の回の S0 までを1回通し（S0〜S5 と S6〜次の回の2本に分けて実行）、各段階で「次の1操作」が光・ママの手・置き先の光で示されることを画面で確認。
- `thumb.png` は実画面（S3、ママと同じ山の形にした所）から作成。

## 既知の問題
- 実機（iPhone / iPad）では未確認。確認はソフトウェア描画のヘッドレス Chromium のみで、実際の速度・音の聞こえ方・音量バランスは未確認。
- 通し確認のあとに入れた小さな変更（ちびおにぎりを 1.2cm→1.5cm 半径相当に、タッチで必ず再開、ママの拍手位置）は、読み込みと開始・S0〜S3 だけ再確認した。ちびの大きさは画面で見直していない。
- 2杯目をよそって大きくする発見は、S1 がすぐ次へ進むため実質たどり着けない。
- 子どもの手が遠く（皿・炊飯器）へ届く時、黄色い袖が長く見える。
- まる（`( )`）の形は、曲げた指でごはんが少し隠れる。
