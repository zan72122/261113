# きゅっきゅっ！おさらをふいてしまおう（gf-261113-nx3）

- 起動: `index.html` をそのまま開く（file:// でも Pages のサブフォルダでも可。外部読み込みなし、1 ファイル）。
- 作り直し: `node build.mjs`（`src/*.js` と `assets/*.jpg` を `index.html` に結合。three.js r149 を同梱）。
- お話: 夕方の台所であわあわの食器を水ですすぐ → 水切りかごから 1 つ選び、ふきんで きゅっきゅっ とふくと キラーン → 光った席へ運んで ことん（大皿・おとうさん・おかあさん・わたしの茶わん・コップ。置くたびに日が暮れる）→ ひもを引いて あかり → ほかほかごはん（おとうさんだけ山盛り）を ぱくっ → ごちそうさま → 食器をシンクへ戻すと、つぎの日の夕方。
- 小さな発見: レバーの上げ下げで水量が変わる／シャボン玉は指で割れる／大皿では水滴が 1 つ ぴゅっ と逃げる／食器ごとに「きゅっ」の高さが違う／かごの食器はどれからでも選べる／あかりは何度でも点け消しできる。
- 確認したこと: 390×844（ヘッドレス Chromium）で読み込み・開始時のコンソールエラーなし。お話を 1 回通して遊び、各段階で「次の 1 操作」が光の輪・きらめき・置き場所の光・（放置時の）半透明の指で示されることを画面で確認。
- 既知の問題: 実機（iPhone / iPad）と横画面、音の聞こえ方は未確認（音は合成のみ）。ヘッドレス環境はソフトウェア描画で非常に遅く、実機での速さ（30fps）は未計測。テクスチャは同じリポジトリの既存画像（木目・壁・布・窓の外の景色）の再利用と、実行時の canvas 生成のみ。
